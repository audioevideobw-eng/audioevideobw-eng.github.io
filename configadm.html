Configuração do projeto (administrador)

Conecta o painel ao projeto Supabase criado para a BW. Esta página é só sua — os convidados não precisam dela.

Conexão com o Supabase

Já configurada — os campos abaixo servem para conferir ou trocar.

Passo a passo (referência)

1. Crie conta grátis em supabase.com → New project (nome: bw-audiovisual).
2. Em Authentication → Providers: Email ativado (padrão).
3. Em Authentication → Users: Add user → Create new user — cadastre você mesmo com senha forte e marque Auto Confirm User.
4. Em Project Settings → API (API Keys): copie a Project URL (https://xxxx.supabase.co). A Publishable key já vem preenchida no painel.
5. Cole a URL ao lado (aceita também o link do dashboard), Salvar e Testar conexão.

Convidar um usuário

No Supabase: Authentication → Users → Add user → e-mail + senha forte → marque Auto Confirm User → Save. A pessoa entra pela página de Acesso com esse e-mail e senha.

Opcional: "Entrar com Google"

1. No Google Cloud Console (console.cloud.google.com) → APIs e Serviços → Credenciais → Criar credenciais → ID do cliente OAuth → Tipo: Aplicativo da Web.
2. Em "Origens JavaScript autorizadas": https://audioevideobw-eng.github.io. Em "URIs de redirecionamento": copie a URL que o Supabase mostra (Authentication → Providers → Google).
3. No Supabase → Authentication → Providers → Google: ative e cole o Client ID e o Client Secret → Save.
4. Pronto: o botão "Entrar com Google" na página de Acesso passa a funcionar.
